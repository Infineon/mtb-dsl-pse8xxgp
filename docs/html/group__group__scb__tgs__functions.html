uint8_t  cntNum,
cy_stc_scb_tgs_config_t const *  config 
)

Initializes the Timeout Generation support in SCB.

Parameters
baseThe pointer to the SCB instance.
cntNumThe counter number (0, 1, 2).
configThe pointer to the configuration structure cy_stc_scb_tgs_config_t.
Returns
cy_en_scb_tgs_status_t
Note
If SCB is already enabled, ensure that the SCB block is disabled Cy_SCB_I2C_Disable before calling this function.
This API is only available for devices containing TGS functionality.
