# I3C - Next-Generation Multi-Protocol Bus Driver for High-Speed Sensor Interfaces

## Overview

The **I3C (Improved Inter-Integrated Circuit)** driver provides an API to implement I3C controller, target, and secondary-controller roles on the Infineon MXI3C hardware block. It supports I3C SDR (up to 12.5 Mbps), HDR-DDR (up to 25 Mbps), as well as legacy I2C Fast-mode Plus devices on the same bus, enabling seamless migration from I2C to I3C in sensor-rich embedded systems.

## Features

- **Dual-protocol bus**: I3C and I2C devices coexist on the same two-wire bus (SDA + SCL)
- **High data rate**: SDR up to 12.5 Mbps; HDR-DDR up to 25 Mbps
- **Common Command Codes (CCC)**: Hardware-accelerated broadcast and direct CCCs for bus management (RSTDAA, ENTDAA, SETDASA, GETPID, etc.)
- **Dynamic Address Assignment (DAA)**: Automatic address allocation for I3C targets via ENTDAA or SETDASA
- **In-Band Interrupt (IBI)**: Targets can request attention from the controller without a dedicated interrupt pin
- **Hot-Join**: New targets can join an active bus without interrupting ongoing communication
- **Low-power callbacks**: DeepSleep and Hibernate callbacks via the SysPm framework

## When to Use

- Interface with MIPI I3C-compliant sensors (IMUs, environmental sensors, camera modules) at high data rates
- Migrate an existing I2C sensor network to I3C while maintaining backward compatibility with legacy I2C devices
- Implement an I3C target device that responds to CCC commands and raises IBIs
- Build a secondary-controller topology where an application processor hands off bus control
- Require interrupt-driven, DMA-friendly sensor data acquisition with minimal pin count

## Prerequisites

### Hardware Requirements

- A device with MXI3C IP
- Dedicated I3C SDA and SCL pins with open-drain drive + internal or external pull-up
- Open-drain enable pin configured with internal pull-up (external pull-up resistors recommended per I3C specification)
- Operating in active power mode (I3C does not operate in DeepSleep)

### Software Requirements

- ModusToolbox 3.x with PDL containing `cy_i3c.h` and `cy_i3c_ccc.h`
- `#include "cy_pdl.h"` or individually `#include "cy_i3c.h"`

### Read Documentation First

- [MXI3C Technical Reference Manual](https://www.infineon.com) — IP block register description
- MIPI I3C Basic specification v1.1 — protocol-level understanding of CCC, DAA, IBI

### Configure in the Tool

1. Open **Device Configurator** → **Peripherals** tab.
2. Expand **Communication** → enable an **I3C** instance; set role: **Controller**, **Target**, or **Secondary Controller**.
3. Configure the clock source; the I3C block requires a dedicated `clk_i3c`. Call `Cy_I3C_SetDataRate()` after init to set SCL low/high phase.
4. Save the `.modus` file to generate `cycfg_peripherals.c/.h` with the `<alias>_config` structure.

| Parameter | Controller Value | Target Value | Description |
|-----------|-----------------|--------------|-------------|
| I3C Mode | `CY_I3C_CONTROLLER` | `CY_I3C_TARGET` | Operating role |
| Clock Source | clk_i3c (16–48 MHz) | clk_i3c | Must be fast enough for desired SCL |
| Data Rate | Up to 12.5 MHz SDR | N/A (set by controller) | Use `Cy_I3C_SetDataRate()` |
| Target Static Address | N/A | 7-bit address | Used before DAA |
| IBI Enable | N/A | true/false | Allow target to raise In-Band Interrupt |

## Quick Start

**Step 1:** Enable an I3C instance in the Device Configurator with Controller role.
**Step 2:** Connect I3C SDA and SCL pins with appropriate pull-ups; connect one or more I3C target devices.
**Step 3:** Register the interrupt handler and enable the I3C interrupt in the NVIC (interrupt is **mandatory** for I3C operation).
**Step 4:** Add the sample code below to `main.c`.

**Expected Outcome:** DAA completes and the controller successfully writes to and reads from the assigned target.

## Sample Code

### Bare Metal I3C Controller Example (main.c)

```c
#include "cy_pdl.h"
#include "cybsp.h"

/* Context is mandatory; must be global */
cy_stc_i3c_context_t i3cContext;

/* I3C interrupt handler - mandatory for operation */
void I3C_Interrupt(void)
{
    Cy_I3C_ControllerInterrupt(mI3C_HW, &i3cContext);
}

/* Callback invoked on bus events (transfer complete, IBI, hot-join) */
void I3C_EventCallback(uint32_t event, void *callbackCtx)
{
    (void)callbackCtx;
    if (event & CY_I3C_CONTROLLER_WR_CMPLT_EVENT)
    {
        /* Write completed */
    }
    if (event & CY_I3C_CONTROLLER_RD_CMPLT_EVENT)
    {
        /* Read completed */
    }
}

int main(void)
{
    /* Initialize device from Device Configurator */
    init_cycfg_all();
    __enable_irq();

    /* I3C config structure generated by Device Configurator */
    Cy_I3C_Init(mI3C_HW, &mI3C_config, &i3cContext);

    /* Register event callback */
    Cy_I3C_RegisterEventCallback(mI3C_HW, I3C_EventCallback, NULL, &i3cContext);

    /* Set bus data rate: SCL up to 12.5 MHz for SDR */
    Cy_I3C_SetDataRate(mI3C_HW, CY_I3C_DATA_RATE_12_5_MHZ, Cy_SysClk_PeriPclkGetFrequency(
                        PCLK_I3C0_CLK), &i3cContext);

    Cy_I3C_Enable(mI3C_HW, &i3cContext);

    /* Perform Dynamic Address Assignment (DAA) for I3C targets */
    cy_stc_i3c_device_t targetList[2];
    targetList[0].staticAddress = 0x63U;  /* Known static address */
    targetList[0].dynamicAddress = 0U;    /* Will be assigned */
    Cy_I3C_AttachI3CDevice(mI3C_HW, &targetList[0], 1U, &i3cContext);

    /* Wait for DAA to complete (handled in interrupt) */
    while (Cy_I3C_GetI3CDeviceCount(mI3C_HW, &i3cContext) == 0U)
    {
        Cy_SysLib_Delay(1U);
    }

    /* Write data to target using assigned dynamic address */
    uint8_t txBuf[] = {0x01U, 0x02U, 0x03U};
    cy_stc_i3c_master_xfer_config_t xfer = {
        .slaveAddress = targetList[0].dynamicAddress,
        .buffer       = txBuf,
        .bufferSize   = sizeof(txBuf),
        .xferPending  = false,
    };
    Cy_I3C_ControllerWrite(mI3C_HW, &xfer, &i3cContext);
    while (CY_I3C_CONTROLLER_BUSY == Cy_I3C_GetBusStatus(mI3C_HW, &i3cContext)) {}

    /* Read response */
    uint8_t rxBuf[3] = {0U};
    xfer.buffer     = rxBuf;
    xfer.bufferSize = sizeof(rxBuf);
    Cy_I3C_ControllerRead(mI3C_HW, &xfer, &i3cContext);
    while (CY_I3C_CONTROLLER_BUSY == Cy_I3C_GetBusStatus(mI3C_HW, &i3cContext)) {}

    for (;;) {}
}
```

### I3C Target Example (fragment)

```c
#include "cy_pdl.h"

cy_stc_i3c_context_t i3cTargetContext;

/* Target interrupt - use target-specific handler to reduce flash usage */
void I3C_Target_Interrupt(void)
{
    Cy_I3C_TargetInterrupt(mI3C_HW, &i3cTargetContext);
}

void i3c_target_init(void)
{
    Cy_I3C_Init(mI3C_HW, &mI3C_target_config, &i3cTargetContext);

    /* Configure RX and TX buffers before enabling */
    static uint8_t readBuf[16];
    static uint8_t writeBuf[16];
    Cy_I3C_TargetConfigReadBuf(mI3C_HW, readBuf, sizeof(readBuf), &i3cTargetContext);
    Cy_I3C_TargetConfigWriteBuf(mI3C_HW, writeBuf, sizeof(writeBuf), &i3cTargetContext);

    Cy_I3C_Enable(mI3C_HW, &i3cTargetContext);
}
```

## Expected Outcome

- After DAA, `Cy_I3C_GetI3CDeviceCount()` returns the number of successfully addressed targets (≥ 1).
- Controller write transaction completes with `CY_I3C_CONTROLLER_WR_CMPLT_EVENT` in the callback.
- Controller read transaction returns the expected data bytes in `rxBuf`.

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---------|-------------|-----|
| Build error: `CY_IP_MXI3C` not defined | Device does not have MXI3C IP | Verify that your target device includes the MXI3C peripheral |
| DAA never completes | Interrupt not enabled or wrong handler | I3C **requires** interrupt; register and `NVIC_EnableIRQ` |
| `Cy_I3C_Init` returns error | Clock not configured | Configure `clk_i3c` divider before calling init |
| IBI not received | IBI not enabled on target | Set IBI enable in target configuration and unmask IBI interrupt |
| Target buffer overflow | Buffer not reconfigured after transaction | Call `Cy_I3C_TargetConfigReadBuf` / `WriteBuf` after every transaction |

| Parameter | Type | Description |
|-----------|------|-------------|
| `i3cMode` | `cy_en_i3c_mode_t` | `CY_I3C_CONTROLLER`, `CY_I3C_TARGET`, or `CY_I3C_SECONDARY_CONTROLLER` |
| `staticAddress` | `uint8_t` | 7-bit I3C/I2C static address (target mode) |
| `dynamicAddress` | `uint8_t` | Pre-assigned dynamic address (optional, target mode) |

| `maxWriteLength` | `uint16_t` | Maximum write data length in bytes |

### Key API Functions

| Function | Description |
|----------|-------------|
| `Cy_I3C_Init()` | Initialize the I3C hardware block |
| `Cy_I3C_Enable()` | Enable the I3C block |
| `Cy_I3C_SetDataRate()` | Configure SCL frequency and phase timings |
| `Cy_I3C_ControllerWrite()` | Initiate a write transaction (non-blocking) |
| `Cy_I3C_ControllerRead()` | Initiate a read transaction (non-blocking) |
| `Cy_I3C_GetBusStatus()` | Poll bus status (busy / idle) |
| `Cy_I3C_AttachI3CDevice()` | Attach I3C target(s) and trigger DAA |
| `Cy_I3C_SendCCC()` | Send a Common Command Code (broadcast or direct) |
| `Cy_I3C_GetI3CDeviceCount()` | Return number of addressed I3C targets on the bus |
| `Cy_I3C_Interrupt()` | General interrupt handler (controller + target role) |
| `Cy_I3C_ControllerInterrupt()` | Controller-only interrupt handler (smaller code size) |
| `Cy_I3C_TargetInterrupt()` | Target-only interrupt handler (smaller code size) |
| `Cy_I3C_DeepSleepCallback()` | SysPm DeepSleep power transition callback |

## Advanced Usage

### Common Command Codes (CCC)

Send a CCC to all devices (broadcast) or a specific device (direct):

```c
/* Broadcast RSTDAA to reset all dynamic addresses */
cy_stc_i3c_ccc_t ccc = {
    .cccId   = CY_I3C_CCC_RSTDAA,
    .isDirect = false,
    .data    = NULL,
    .dataLen = 0U,
};
Cy_I3C_SendCCC(mI3C_HW, &ccc, &i3cContext);
```

### In-Band Interrupt (IBI) Handling

The controller must unmask the IBI interrupt source and register a callback. When a target asserts IBI, the controller acknowledges it and the callback is invoked with the target's dynamic address and optional IBI data byte.

### Hot-Join

Enable `hotJoinEnable` in the target config. The controller must have hot-join acceptance enabled (not masked). When a new target powers on and asserts Hot-Join, the controller automatically runs DAA for the new device.

### Number of Addressable Targets

In controller mode the MXI3C block supports up to **11 addressable target devices** simultaneously on the bus.

## Industry Standards

- MIPI I3C Basic Specification v1.1 (MIPI Alliance)
- I2C-bus specification Fast-mode Plus (1 Mbps) — for legacy I2C targets on the I3C bus
