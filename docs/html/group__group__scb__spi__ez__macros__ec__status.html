EZ Mode EC Interrupt Flags
PDL API Reference » SCB (Serial Communication Block) » EZSPI (SCB) » Macros

General Description

Status flags from INTR_SPI_EC register for externally-clocked EZ operation.

These flags are set by the external-clock domain logic and are valid in both ACTIVE and DEEPSLEEP power modes (when EC_AM_MODE=1, EC_OP_MODE=1).
