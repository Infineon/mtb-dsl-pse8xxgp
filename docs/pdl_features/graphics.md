# Graphics - 2D GPU and Multi-Layer Display Controller

## Overview

The Graphics Sub System (GFXSS) driver (`cy_graphics`) provides an application interface to the
**MXS22GFXSS IP**, combining a 2D vector GPU (Vivante GCNano, exposed via VGLite API), a multi-layer
Display Controller (DCNano), and an integrated MIPI DSI host controller. It enables hardware-accelerated
2D rendering up to 200 Mpix/s with display output up to 1024×768 @ 60 Hz.

---

## Features

- **2D GPU (Vivante GCNano)** with VGLite API: vector graphics, Bézier curves, fill patterns, Porter-Duff blending
- Fill rate up to **200 Mpix/s**; 2.5D geometry (no depth coordinate)
- **Display Controller (DCNano)** with 3 display layers:
  - Graphics/Video layer: ARGB or YUV (4:2:0/4:2:2), tiled and linear formats
  - Overlay 0: ARGB or YUV with alpha blending
  - Overlay 1: ARGB linear only, RLAD decompression support
- Display output modes: **MIPI-DSI DPI-2 / DBI-2**, GPIO DPI, and DBI Type A/B/C
- **Display modes up to 1024 × 768 pixels @ 60 Hz** (64 MHz pixel clock) with 24-bit color
- Cursor overlay with foreground/background colors
- **Gamma correction**, color keying, spatial dithering
- **RLAD (Run-Length Adaptive Dithering)** lossless image decompression on Overlay 1
- Single, double, and split framebuffer update strategies

## Prerequisites

### Hardware Requirements

- Device with MXS22GFXSS peripheral
- Display panel: MIPI DSI (DPI/DBI) or parallel DPI/DBI interface
- Sufficient RAM for GPU heap and framebuffers (typically ≥ 3 MB contiguous for GPU heap)
- GPIO reset pin connected to display panel reset input

### Software Requirements

- ModusToolbox™ 3.x or later
- PDL version 1.x with `cy_graphics.h` and `cy_mipidsi.h`
- VGLite library (`vg_lite.h`, `vg_lite_platform.h`) and Vivante DC headers (`viv_dc_*.h`)
- Add `COMPONENTS+=GFXSS` in your application's `.mk` file to include GFXSS component
- Include `cy_pdl.h` or individual headers to access all PDL declarations

### Configure in the Tool

1. Open **Device Configurator** in ModusToolbox.
2. Enable the **GFXSS** block and configure the GFXSS clock frequency.
3. For MIPI DSI displays: configure MIPIDSI lanes, pixel clock, and display resolution.
4. Assign display data pins and the display reset GPIO.
5. Enable GFXSS interrupts: `gfxss_interrupt_dc_IRQn` (DC) and optionally GPU interrupt.

## Quick Start

### Step-by-Step

1. Call `init_cycfg_all()` to apply pin mux and clock settings generated by Device Configurator.
2. Register `Cy_GFXSS_DeepSleepCallback` with `Cy_SysPm_RegisterCallback()` for power management.
3. Fill `cy_stc_gfx_config_t` with DC config, optional GPU config, MIPI DSI config, and clock frequency.
4. Call `Cy_GFXSS_Init()` to initialize the entire GFXSS pipeline.
5. Register and enable the DC interrupt (`gfxss_interrupt_dc_IRQn`).
6. Initialize the display panel via `Cy_MIPIDSI_WritePacket()` (DCS command sequence).
7. Initialize VGLite GPU with `vg_lite_init_mem()` and `vg_lite_init()`.
8. Allocate framebuffers with `vg_lite_allocate()`.
9. Render content using VGLite APIs (`vg_lite_clear()`, `vg_lite_draw()`, `vg_lite_finish()`).
10. Submit the rendered framebuffer to the DC with `Cy_GFXSS_Set_FrameBuffer()`.

### Sample Code

```c
#include "cy_pdl.h"
#include "cy_graphics.h"
#include "vg_lite.h"
#include "vg_lite_platform.h"
#include "cycfg.h"

#define GPU_HEAP_SIZE   (3U * 1024U * 1024U)   /* 3 MB contiguous GPU heap */
#define FB_WIDTH        1024U
#define FB_HEIGHT       600U

__attribute__((section(".cy_gpu_buf"))) uint8_t contiguous_memory[GPU_HEAP_SIZE];

static cy_stc_gfx_context_t gfx_context;
static vg_lite_buffer_t     framebuffer;
static volatile bool        fb_pending = false;
GFXSS_Type                 *base = (GFXSS_Type *)GFXSS;

/* DC interrupt clears after vsync; signals that framebuffer flip is done */
void DC_Interrupt_Handler(void)
{
    Cy_GFXSS_Clear_DC_Interrupt(base, &gfx_context);
    fb_pending = false;
}

int main(void)
{
    /* System init: clocks, pins, peripherals */
    init_cycfg_all();
    __enable_irq();

    /* Register power management callback */
    cy_stc_syspm_callback_params_t pmParams = { base, &gfx_context };
    cy_stc_syspm_callback_t pmCb = { Cy_GFXSS_DeepSleepCallback, CY_SYSPM_DEEPSLEEP,
                                     0U, &pmParams, NULL, NULL, 0U };
    Cy_SysPm_RegisterCallback(&pmCb);

    /* Initialize graphics subsystem using Device Configurator-generated GFXSS_config */
    cy_en_gfx_status_t status = Cy_GFXSS_Init(base, &GFXSS_config, &gfx_context);
    if (status != CY_GFX_SUCCESS) { /* handle error */ }

    /* Enable DC interrupt */
    cy_stc_sysint_t dcIrqCfg = { .intrSrc = gfxss_interrupt_dc_IRQn, .intrPriority = 3U };
    Cy_SysInt_Init(&dcIrqCfg, DC_Interrupt_Handler);
    NVIC_EnableIRQ(gfxss_interrupt_dc_IRQn);

    /* Initialize MIPI DSI display panel (DCS command sequence) */
    GFXSS_MIPIDSI_Type *dsi = (GFXSS_MIPIDSI_Type *)GFXSS_GFXSS_MIPIDSI;
    uint8_t cmd_display_on[] = { 0x29, 0x00 };
    Cy_MIPIDSI_WritePacket(dsi, cmd_display_on, sizeof(cmd_display_on));

    /* Initialize VGLite GPU */
    vg_module_parameters_t gpu_params = {
        .register_mem_base    = (uint32_t)GFXSS_GFXSS_GPU_GCNANO,
        .gpu_mem_base[0]      = 0U,
        .contiguous_mem_base[0] = (volatile void *)contiguous_memory,
        .contiguous_mem_size[0] = GPU_HEAP_SIZE,
    };
    vg_lite_init_mem(&gpu_params);
    vg_lite_init(FB_WIDTH, FB_HEIGHT);

    /* Allocate framebuffer */
    framebuffer.width  = FB_WIDTH;
    framebuffer.height = FB_HEIGHT;
    framebuffer.format = VG_LITE_BGR565;
    vg_lite_allocate(&framebuffer);

    /* Clear framebuffer to red */
    vg_lite_clear(&framebuffer, NULL, 0xFFFF0000U);
    vg_lite_finish();

    /* Submit to Display Controller */
    Cy_GFXSS_Set_FrameBuffer(base, (uint32_t *)framebuffer.address, &gfx_context);
    GFXSS->GFXSS_DC.DCNANO.GCREGPANELCONTROL |=
        GFXSS_DC_DCNANO_GCREGPANELCONTROL_GCREGPANELCONTROL_VALID_Msk;
    fb_pending = true;
    while (fb_pending) { }   /* wait for vsync flip */

    for (;;) { /* render loop */ }
}
```

### Expected Outcome

- The 1024×600 display shows a solid red framebuffer after initialization.
- `fb_pending` is cleared by the DC interrupt on the next vsync, confirming buffer flip.
- VGLite draw calls can be added between `vg_lite_clear()` and `vg_lite_finish()` to render vector content.

## Troubleshooting

| Symptom | Likely Cause | Resolution |
|---|---|---|
| `Cy_GFXSS_Init()` returns `CY_GFX_BAD_PARAM` | Invalid config (NULL pointers, unsupported display type) | Verify all fields in `cy_stc_gfx_config_t` are populated correctly |
| Display shows white/no image | MIPI DSI panel not initialized | Ensure DCS command sequence completes without `CY_MIPIDSI_TIMEOUT` errors |
| GPU output corrupt / artifacts | Contiguous GPU heap not 128-byte aligned or too small | Ensure `contiguous_memory` is in the correct section with at least 3 MB |
| Framebuffer tearing | Missing vsync synchronization | Wait on `fb_pending` flag cleared by DC interrupt before starting next draw |
| `vg_lite_allocate()` fails | No contiguous memory for framebuffer | Increase GPU heap size or use a statically declared 128-byte aligned buffer |
| RLAD decoder error (`CY_GFX_RLAD_BUF_TOO_SMALL`) | Incorrect `compressed_image_size` in RLAD config | Regenerate the RLAD image header with the correct compressed size field |
| Driver not compiling | Missing `CY_IP_MXS22GFXSS` | Target must have MXS22GFXSS peripheral; add `COMPONENTS+=GFXSS` in `.mk` |

## Advanced Usage

### Double-Buffering for Tear-Free Animation

Set `display_update_type = GFX_DOUBLE_BUFFER`. Maintain two VGLite buffers (`buffer` and `buffer1`); alternate rendering to the back buffer while the DC displays the front buffer. After `vg_lite_finish()`, call `Cy_GFXSS_Set_FrameBuffer()` with the just-rendered buffer, then wait for the DC interrupt before swapping.

### Multi-Layer Composition

Configure all three layers in `cy_stc_gfx_dc_config_t`. Set `zorder` for each layer; higher values appear on top. Use `alpha_mode` (`CY_VIV_LAYER_ALPHA_*`) to control per-pixel and global alpha blending. The DC composites all enabled layers in hardware with no CPU involvement during display output.

### RLAD Compressed Image Display

Store compressed images in flash using the RLAD encoder tool. Configure `cy_stc_gfx_rlad_cfg_t` with the image address, dimensions, compressed size, and compression mode. Use `Cy_GFXSS_Set_RLAD_FrameBuffer()` to point the DC at the compressed image; the hardware RLAD decoder decompresses on-the-fly at display scan rate.

### YUV Video Playback

Set layer `input_format_type` to a YUV format (e.g., `NV12` for semi-planar YUV 4:2:0). Call `Cy_GFXSS_Set_FrameBuffer_YUV()` with separate Y-plane and UV-plane buffer pointers. Align Y and UV buffers to 64 bytes; the DC performs YUV-to-RGB upsampling in hardware.
