Data Fields
uint32_t count Initial count value.
uint32_t reload Counter reload value.
bool reloadTx Reload the counter on data transmission out of TX FIFO.
bool reloadRx Reload the counter on data reception into RX FIFO.
bool reloadClkFall Reload the counter on falling edge of I2C SCL or SPI SCLK.
bool reloadClkRise Reload the counter on rising edge of I2C SCL or SPI SCLK.
bool reloadUartStart Reload the counter on falling edge of UART start bit.
bool reloadSpiSel Reload the counter on falling edge of SPI select (only single supported)
bool reloadI2cStart Reload the counter on I2C start/restart condition.
bool reloadI2cAckRise Reload the counter on transmitted/received I2C ACK on the rising edge of SCL.
bool reloadI2cAckFall Reload the counter on transmitted/received I2C ACK on the falling edge of SCL.
bool reloadWakeup Reload the counter on transition from DeepSleep to Active power mode.
bool gateClkHigh Gate/Pause the counter while I2C SCL or SPI SCLK is high.
bool gateClkLow Gate/Pause the counter while I2C SCL or SPI SCLK is low.
bool gateFrame Gate/Pause the counter during active communication frame.
bool gateFrameN Gate/Pause the counter outside of active communication frame.
bool stopClkFall Stop the counter on falling edge of I2C SCL or SPI SCLK.
bool stopClkRise Stop the counter on rising edge of I2C SCL or SPI SCLK.
bool stopUartStop Stop the counter on UART stop bit or RX frame error.
bool stopSpiSel Stop the counter on rising edge of SPI select (only single supported)
bool stopI2cStop Stop the counter on I2C stop condition.
bool uartDirection Direction of UART triggers (TX=0, RX=1)
bool enableReset Communication and FIFO reset on timer expiration.
