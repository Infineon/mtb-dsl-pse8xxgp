GFXSS (Graphics Sub System)
PDL API Reference

General Description

The Graphics Sub System driver provides an application interface for configuring graphics IP.

GFXSS features graphics rendering to memory and control of one display:

  • Vector Graphics and Blit Operations.
  • Rendering fill rate up to 200Mpix/s.
  • MIPI-DSI displays with DPI (pixel interface) or DBI Type B (bus interface).
  • GPIO displays with parallel or serial interface (DPI and all DBI types).
  • Display modes up to 1024 x 768 pixels @ 60 Hz (64 MHz) with 24-bit color resolution.

Graphics Processing Unit (GPU):

  • Display list command processing.
  • 2D geometry processing with perspective correction and no depth coordinate (=2.5D).
  • Tessellation of line, quad and Bezier curve primitives.
  • Vector graphics rasterization for linear and curved paths.
  • Textured, solid and linear fill pattern.
  • 8 Porter Duff blending modes.
  • Various ARGB formats for textures and destination buffers (8, 16 or 32 bpp).
  • Color palette for textures (1, 2, 4 or 8 index bpp).
  • Chroma sub-sampled destination buffers (YUV 4:2:2 or 4:2:0 with 16 or 12 bpp).

Display Controller (DC):

  • 3 display layers with transparency (alpha blending).
  • 2 layers with support for YUV up-sampling.
  • 1 layer with support for RLAD decompression.
  • Cursor overlay.
  • Gamma correction.
  • Color keying.
  • Spatial dithering.
  • Various ARGB formats (16 or 32 bpp).
  • Various YUV formats, packed and semi-planar (12 or 16 bpp).
  • Video Timing Generator for DPI displays.
  • Configuration and Frame Buffer update for DBI displays (DCS write only).

MIPI-DSI Host Controller and D-PHY (MIPIDSI)

  • DPI-2 and and DBI-2 Type B displays.
  • Up to 2 data lanes, max 1.5 Gbps per lane.
  • PLL for high-speed mode clock generation.
  • Generic command interface (DCS and proprietary read & write).
  • Video Pattern generator.
  • Ultra-Low-Power mode with disabled PLL.
  • Tearing Effect interrupt for DBI displays.
  • Shutdown and Color Mode control for DPI displays.

The functions and other declarations used in this driver are in cy_graphics.h. You can include cy_pdl.h to get access to all functions and declarations in the PDL.

Interrupt-Driven DBI Frame Transfer

For MIPI DSI command mode (DBI) displays, the GFXSS driver provides an interrupt-driven frame transfer mechanism that eliminates CPU polling and delay-based synchronization. The display frame is divided into slices that fit within the DBI command size limit (DBI_SCLICE_LIMIT_IN_BYTES = 65536 bytes). Each slice is automatically chained by the DC interrupt handler after the previous slice completes.

The blocking API Cy_GFXSS_Transfer_Frame uses a polling loop with Cy_SysLib_Rtos_DelayUs() to wait for each slice. The non-blocking API Cy_GFXSS_Transfer_Frame_Async offloads this to the GFXSS_DC_IRQ interrupt, freeing the CPU for other work during the transfer.

Tearing Effect (TE) Synchronization

When TE is enabled on the panel (MIPI DCS command 0x35 set to a non-zero mode), the driver sets CMD_MODE_CFG.TEAR_FX_EN in the DWC MIPI DSI Host. This causes the DSI host to automatically perform a Bus Turn Around (BTA) and wait for the panel's TE signal before transmitting the first DBI write command. This provides hardware-level tear-free display updates without requiring explicit TE interrupt handling in the application.

Integration Steps

  1. Enable TE on the display panel during initialization (MIPI DCS command 0x35, e.g. 0x02 for VSync + HSync mode).
  2. Register a completion callback with Cy_GFXSS_RegisterTransferCompleteCallback.
    • RTOS: the callback gives a semaphore.
    • Bare-metal: the callback sets a volatile flag.
  3. Register an ISR for GFXSS_DC_IRQ that calls Cy_GFXSS_DC_DBI_InterruptHandler(). The PDL internally invokes the registered callback when all slices are done.
  4. In the display flush path, wait for the previous transfer to finish (semaphore take or flag poll), update the frame buffer pointer with Cy_GFXSS_Set_FrameBuffer(), and call Cy_GFXSS_Transfer_Frame_Async().

Code Example (FreeRTOS)

#include "cy_graphics.h"
#include "FreeRTOS.h"
#include "semphr.h"
static SemaphoreHandle_t frame_tx_sem;
static cy_stc_gfx_context_t gfx_context_rtos;
/* Callback invoked from ISR when all DBI slices complete */
static void on_transfer_complete_rtos(void)
{
BaseType_t woken = pdFALSE;
xSemaphoreGiveFromISR(frame_tx_sem, &woken);
portYIELD_FROM_ISR(woken);
}
/* ISR: DC interrupt handler for DBI slice completion */
static void dc_dbi_irq_handler_rtos(void)
{
Cy_GFXSS_DC_DBI_InterruptHandler((GFXSS_Type*)GFXSS, &gfx_context_rtos);
}
void display_async_init_rtos(void)
{
frame_tx_sem = xSemaphoreCreateBinary();
xSemaphoreGive(frame_tx_sem); /* Available for the first flush */
/* Register completion callback (PDL calls it from ISR context) */
Cy_GFXSS_RegisterTransferCompleteCallback(&gfx_context_rtos,
on_transfer_complete_rtos);
const cy_stc_sysint_t dc_dbi_cfg = {
.intrSrc = GFXSS_DC_IRQ,
.intrPriority = 3U
};
Cy_SysInt_Init(&dc_dbi_cfg, dc_dbi_irq_handler_rtos);
NVIC_EnableIRQ(GFXSS_DC_IRQ);
NVIC_ClearPendingIRQ(GFXSS_DC_IRQ);
}
/* Display flush callback (LVGL / custom framework) */
void disp_flush_rtos(lv_display_t *disp, const lv_area_t *area, uint8_t *px_map)
{
(void)area;
xSemaphoreTake(frame_tx_sem, portMAX_DELAY);
Cy_GFXSS_Set_FrameBuffer((GFXSS_Type*)GFXSS,
(uint32_t*)px_map, &gfx_context_rtos);
Cy_GFXSS_Transfer_Frame_Async((GFXSS_Type*)GFXSS, &gfx_context_rtos);
lv_disp_flush_ready(disp);
}

Code Example (Bare-Metal)

#include "cy_graphics.h"
static volatile bool frame_tx_done = true;
static cy_stc_gfx_context_t gfx_context_bm;
/* Callback invoked from ISR when all DBI slices complete */
static void on_transfer_complete_bm(void)
{
frame_tx_done = true;
}
/* ISR: DC interrupt handler for DBI slice completion */
static void dc_dbi_irq_handler_bm(void)
{
Cy_GFXSS_DC_DBI_InterruptHandler((GFXSS_Type*)GFXSS, &gfx_context_bm);
}
void display_async_init_bm(void)
{
/* Register completion callback */
Cy_GFXSS_RegisterTransferCompleteCallback(&gfx_context_bm,
on_transfer_complete_bm);
const cy_stc_sysint_t dc_dbi_cfg = {
.intrSrc = GFXSS_DC_IRQ,
.intrPriority = 3U
};
Cy_SysInt_Init(&dc_dbi_cfg, dc_dbi_irq_handler_bm);
NVIC_EnableIRQ(GFXSS_DC_IRQ);
NVIC_ClearPendingIRQ(GFXSS_DC_IRQ);
}
/* Display flush (polling-based for bare-metal main loop) */
void disp_flush_bm(uint8_t *px_map)
{
/* Wait for previous transfer (WFI sleeps CPU between interrupts) */
while (!frame_tx_done) { __WFI(); }
frame_tx_done = false;
Cy_GFXSS_Set_FrameBuffer((GFXSS_Type*)GFXSS,
(uint32_t*)px_map, &gfx_context_bm);
Cy_GFXSS_Transfer_Frame_Async((GFXSS_Type*)GFXSS, &gfx_context_bm);
}
