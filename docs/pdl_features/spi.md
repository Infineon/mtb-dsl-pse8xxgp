# SPI (Serial Peripheral Interface) - SCB-Based SPI Master/Slave Driver

## Overview

The **SPI driver** configures an SCB hardware block as an SPI master or slave, supporting Motorola, Texas Instruments, and National Semiconductor MicroWire sub-modes. It provides configurable data widths (4–32 bits), four clock polarity/phase modes, multiple slave-select lines, and both interrupt-driven and DMA-assisted transfers.

## Features

- **Master and Slave modes** on a single SCB instance
- **Sub-modes**: Motorola SPI (modes 0–3), Texas Instruments SPI, National Semiconductor MicroWire
- **Data width**: 4 to 32 bits per frame
- **Configurable oversample** (master): determines SCLK frequency as `clk_scb / oversample`
- **Up to 4 slave-select (SS) lines** with configurable active polarity
- **TX/RX FIFOs** with configurable trigger levels for efficient DMA or interrupt operation
- **MSb-first or LSb-first** bit ordering
- **EZ-SPI (autonomous slave)**: hardware-managed transfers using internal EZ buffer
- **Activity-detect Wake-from-DeepSleep**: device wakes on first SS assertion
- **DMA integration**: FIFO watermark triggers for zero-copy data movement

## When to Use

- Interface with external flash, DACs, ADCs, or display controllers over SPI up to tens of MHz
- Build multi-drop SPI bus designs using up to four independent slave-select lines
- Implement high-speed data streaming to/from peripherals using DMA
- Autonomous SPI slave operation (EZ-SPI) while CPU sleeps
- Low-power designs with SS-assertion wake from DeepSleep

## Prerequisites

### Hardware Requirements

- A device with an SCB IP block
- Dedicated SCB pins routed to the I/O mux (HSIOM) for MOSI, MISO, SCLK, and SS
- SPI slave (or master) device connected with matching CPOL/CPHA configuration

### Software Requirements

- ModusToolbox 3.x or newer
- `cy_pdl.h` (or individual header: `cy_scb_spi.h`)

### Configure in the Tool

1. Open **Device Configurator** and select the **Peripherals** tab.
2. Expand **Communication** → enable an **SCB** instance and choose the **SPI** personality.
3. Configure the parameters in the Parameters pane (see table below).
4. Click **File → Save**; the tool generates `cycfg_peripherals.c/.h` with ready-to-use `<alias>_config` and `<alias>_context` structures.
5. Call `init_cycfg_all()` at the start of `main()` to apply clocking and pin routing.

**SPI personality parameters (spi-\*.cypersonality)**

| Parameter | Value for Master Motorola Mode 0 | Notes |
|-----------|----------------------------------|-------|
| SPI Mode | Master | Master / Slave |
| Sub Mode | Motorola | TI / MicroWire also supported |
| SCLK Mode | CPOL=0, CPHA=0 | Modes 0–3 |
| Data Width | 8 | 4–32 bits |
| Oversample | 16 | Master: data rate = clk_scb / oversample |

## Quick Start

**Step 1:** Enable an SCB in SPI Master personality, Motorola Mode 0, 8-bit, 1 MHz in Device Configurator.
**Step 2:** Connect MOSI, MISO, SCLK, SS to the SPI slave.
**Step 3:** Add the sample code below to `main.c`.
**Step 4:** Build, program, and verify data exchange.

**Expected Outcome:** Data transmitted on MOSI is simultaneously received on MISO (loopback test passes).

### Sample Code

#### Bare Metal SPI Master Example (main.c)

```c
#include "cy_pdl.h"
#include "cybsp.h"

cy_stc_scb_spi_context_t spiContext;

int main(void)
{
    init_cycfg_all();
    __enable_irq();

    /* Initialize SPI master - config generated by Device Configurator */
    Cy_SCB_SPI_Init(SCB1, &scb_1_spi_config, &spiContext);
    Cy_SCB_SPI_Enable(SCB1);

    uint32_t txData = 0xA5A5A5A5UL;

    /* Transfer one 32-bit word */
    Cy_SCB_SPI_Write(SCB1, txData);
    while (Cy_SCB_SPI_GetNumInTxFifo(SCB1) != 0U) {}   /* wait TX empty */
    while (Cy_SCB_SPI_IsBusBusy(SCB1)) {}               /* wait complete */

    uint32_t rxData = Cy_SCB_SPI_Read(SCB1);
    (void)rxData;

    for (;;) {}
}
```

#### Multi-Byte SPI Transfer Example

```c
#include "cy_pdl.h"
#include "cybsp.h"

#define BUF_SIZE (8U)

cy_stc_scb_spi_context_t spiContext;

int main(void)
{
    init_cycfg_all();
    __enable_irq();

    Cy_SCB_SPI_Init(SCB1, &scb_1_spi_config, &spiContext);
    Cy_SCB_SPI_Enable(SCB1);

    uint8_t txBuf[BUF_SIZE] = {0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08};
    uint8_t rxBuf[BUF_SIZE] = {0};

    /* Assert slave select */
    Cy_SCB_SPI_SetActiveSlaveSelect(SCB1, CY_SCB_SPI_SLAVE_SELECT0);

    /* Write buffer */
    for (uint32_t i = 0U; i < BUF_SIZE; i++)
    {
        Cy_SCB_SPI_Write(SCB1, txBuf[i]);
    }

    /* Wait for transfer to complete */
    while (Cy_SCB_SPI_IsBusBusy(SCB1)) {}

    /* Read received data */
    for (uint32_t i = 0U; i < BUF_SIZE; i++)
    {
        rxBuf[i] = (uint8_t)Cy_SCB_SPI_Read(SCB1);
    }

    for (;;) {}
}
```

### Expected Outcome

- **SPI Master**: Transmit FIFO empties and `rxData` holds the byte(s) returned by the slave (or loopback value).
- **Multi-byte transfer**: All 8 bytes transmitted; `rxBuf` populated with slave responses.

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---------|-------------|-----|
| SPI data garbled | CPOL/CPHA mismatch | Match `sclkMode` between master and slave |
| No SCLK output | Oversample set to 0 or clk_scb disabled | Verify clock configuration in Device Configurator |
| Slave not responding | Wrong SS polarity or pin | Check `ssPolarity` and HSIOM routing |
| Data shifted by 1 bit | MSb/LSb mismatch | Ensure `enableMsbFirst` matches slave expectations |
| `Cy_SCB_SPI_Init` returns error | SCB not enabled in Device Configurator | Enable the peripheral and re-save `.modus` |
| Transfer hangs | TX FIFO full, no FIFO drain | Enable interrupt or DMA to drain TX FIFO |

## Configuration Parameters Reference

**SPI (`cy_stc_scb_spi_config_t`)**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `spiMode` | `cy_en_scb_spi_mode_t` | `CY_SCB_SPI_MASTER` | Master / Slave |
| `subMode` | `cy_en_scb_spi_sub_mode_t` | `CY_SCB_SPI_MOTOROLA` | Motorola / TI / MicroWire |
| `sclkMode` | `cy_en_scb_spi_sclk_mode_t` | `CY_SCB_SPI_CPHA0_CPOL0` | Modes 0–3 |
| `oversample` | `uint32_t` | 16 | Clocks per SCLK half-period (master) |
| `rxDataWidth` | `uint32_t` | 8 | RX frame width in bits (4–32) |
| `txDataWidth` | `uint32_t` | 8 | TX frame width in bits (4–32) |
| `enableMsbFirst` | `bool` | true | Bit order: MSb first (true) |
| `ssPolarity` | mask | LOW | Slave select active polarity, per SS line |
| `rxFifoTriggerLevel` | `uint32_t` | 0 | RX FIFO DMA/interrupt trigger level |
| `txFifoTriggerLevel` | `uint32_t` | 0 | TX FIFO DMA/interrupt trigger level |

## Advanced Usage and Examples

### Wake-from-DeepSleep

SPI supports activity-detect wakeup: the device wakes from DeepSleep on the first SS assertion.

Register `Cy_SCB_SPI_DeepSleepCallback` with `Cy_SysPm_RegisterCallback()` before entering DeepSleep.

### DMA Integration

Set `rxFifoTriggerLevel` and `txFifoTriggerLevel` in the SPI config structure to the desired FIFO watermarks. Connect the SCB DMA triggers (`TRIG_IN_MUX_*`) to a DMA channel for zero-copy transfers. Refer to the [DMA driver documentation](dma.md) for DMA channel setup.
