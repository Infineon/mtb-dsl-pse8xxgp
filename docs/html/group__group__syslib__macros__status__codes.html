enum cy_en_pdl_rslt_module_t

PDL result module identifiers.

Single source of truth for driver IDs in the CY_RSLT_MODULE_DRIVERS_PDL_BASE range (0x0000-0x007F). All driver CY_*_ID macros reference members of this enum via CY_PDL_DRV_ID().
