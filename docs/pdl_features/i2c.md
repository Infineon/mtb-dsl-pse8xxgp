# I2C (Inter-Integrated Circuit) - SCB-Based I2C Master/Slave Driver

## Overview

The **I2C driver** configures an SCB hardware block as an I2C master, slave, or master-slave, supporting Standard-mode (100 kbps), Fast-mode (400 kbps), and Fast-mode Plus (1 Mbps) data rates. It provides both low-level register access and high-level interrupt-driven transfer APIs, along with EZ-I2C autonomous slave mode for CPU-free operation.

## Features

- **Master, Slave, and Master-Slave modes** on a single SCB instance
- **Data rates**: Standard-mode (100 kbps), Fast-mode (400 kbps), Fast-mode Plus (1 Mbps)
- **TX/RX FIFOs** with configurable trigger levels to reduce clock stretching
- **EZ-I2C (autonomous slave)**: hardware-managed read/write to internal SRAM buffer without CPU intervention
- **Hardware EZ mode** (on supported devices): uses SCB's 256-byte `EZ_DATA` dual-port memory — no clock stretching
- **Address-match Wake-from-DeepSleep**: device wakes when master addresses it
- **Digital filter** for Fast-mode Plus noise immunity
- **DMA integration**: configurable FIFO trigger levels for zero-copy DMA transfers
- **Callback-based interrupt model** for non-blocking operation

## When to Use

- Read/write sensors and EEPROMs on an I2C bus at 100 kbps, 400 kbps, or 1 Mbps
- Implement an I2C slave that responds autonomously (EZ-I2C) while the CPU sleeps
- Multi-master bus arbitration scenarios
- Low-power designs requiring address-match wake from DeepSleep
- High-throughput I2C transfers using DMA to reduce CPU overhead

## Prerequisites

### Hardware Requirements

- A device with an SCB IP block
- Dedicated SCB pins routed to the I/O mux (HSIOM) for SDA and SCL
- External 4.7 kΩ pull-up resistors on SDA and SCL lines
- I2C slave device(s) connected to the bus

### Software Requirements

- ModusToolbox 3.x or newer
- `cy_pdl.h` (or individual header: `cy_scb_i2c.h`, `cy_scb_ezi2c.h`)

### Configure in the Tool

1. Open **Device Configurator** and select the **Peripherals** tab.
2. Expand **Communication** → enable an **SCB** instance and choose the **I2C** or **EZI2C** personality.
3. Configure the parameters in the Parameters pane (see table below).
4. Click **File → Save**; the tool generates `cycfg_peripherals.c/.h` with ready-to-use `<alias>_config` and `<alias>_context` structures.
5. Call `init_cycfg_all()` at the start of `main()` to apply clocking and pin routing.

**I2C personality parameters (i2c-\*.cypersonality)**

| Parameter | Value for Master 400 kbps | Notes |
|-----------|--------------------------|-------|
| Mode | Master | Slave, Master-Slave also available |
| Data Rate | 400 kbps | 100/400/1000 kbps |
| Use Rx FIFO | true | Reduces clock stretching |
| Use Tx FIFO | true | Reduces clock stretching |

## Quick Start

**Step 1:** Enable an SCB in I2C Master personality at 400 kbps in Device Configurator.
**Step 2:** Connect SCL/SDA with 4.7 kΩ pull-ups; connect an I2C slave device.
**Step 3:** Add the sample code below to `main.c`.
**Step 4:** Build, program, and verify slave responds.

**Expected Outcome:** A write+read transaction completes; slave responds with expected data.

### Sample Code

#### Bare Metal I2C Master Example (main.c)

```c
#include "cy_pdl.h"
#include "cybsp.h"

#define I2C_SLAVE_ADDR   (0x08U)
#define TX_BUF_SIZE      (3U)

cy_stc_scb_i2c_context_t i2cContext;

int main(void)
{
    init_cycfg_all();
    __enable_irq();

    /* Initialize I2C master - config generated by Device Configurator */
    Cy_SCB_I2C_Init(SCB3, &scb_3_i2c_config, &i2cContext);
    Cy_SCB_I2C_Enable(SCB3);

    uint8_t txBuf[TX_BUF_SIZE] = {0x00, 0x01, 0xFF};
    uint8_t rxBuf[1]           = {0x00};

    /* Write 3 bytes to slave */
    cy_stc_scb_i2c_master_xfer_config_t xfer = {
        .slaveAddress = I2C_SLAVE_ADDR,
        .buffer       = txBuf,
        .bufferSize   = TX_BUF_SIZE,
        .xferPending  = false,
    };
    Cy_SCB_I2C_MasterWrite(SCB3, &xfer, &i2cContext);
    while (CY_SCB_I2C_MASTER_BUSY == Cy_SCB_I2C_MasterGetStatus(SCB3, &i2cContext)) {}

    /* Read 1 byte from slave */
    xfer.buffer     = rxBuf;
    xfer.bufferSize = 1U;
    Cy_SCB_I2C_MasterRead(SCB3, &xfer, &i2cContext);
    while (CY_SCB_I2C_MASTER_BUSY == Cy_SCB_I2C_MasterGetStatus(SCB3, &i2cContext)) {}

    for (;;) {}
}
```

#### EZ-I2C Autonomous Slave Example

```c
#include "cy_pdl.h"
#include "cybsp.h"

#define EZI2C_BUF_SIZE    (32U)
#define RW_BOUNDARY       (4U)   /* First 4 bytes read-write, rest read-only */

cy_stc_scb_ezi2c_context_t ezi2cContext;
uint8_t sharedBuf[EZI2C_BUF_SIZE];

void EZI2C_Interrupt(void)
{
    Cy_SCB_EZI2C_Interrupt(SCB2, &ezi2cContext);
}

int main(void)
{
    init_cycfg_all();
    __enable_irq();

    /* Reference the generated EZI2C config from Device Configurator */
    Cy_SCB_EZI2C_Init(SCB2, &scb_2_ezi2c_config, &ezi2cContext);
    Cy_SCB_EZI2C_SetBuffer1(SCB2, sharedBuf, sizeof(sharedBuf), RW_BOUNDARY, &ezi2cContext);
    Cy_SCB_EZI2C_Enable(SCB2);

    for (;;)
    {
        /* CPU can sleep; EZ-I2C handles transactions autonomously */
        Cy_SysPm_CpuEnterDeepSleep(CY_SYSPM_WAIT_FOR_INTERRUPT);
    }
}
```

#### Hardware EZ Mode (PSOC Edge)

```c
const cy_stc_scb_ezi2c_config_t hwEzConfig = {
    .numberOfAddresses   = CY_SCB_EZI2C_ONE_ADDRESS,
    .slaveAddress1       = 0x08U,
    .subAddressSize      = CY_SCB_EZI2C_SUB_ADDR8_BITS,
    .enableHwEzMode      = true,
};
Cy_SCB_EZI2C_Init(SCB2, &hwEzConfig, &ezi2cContext);
Cy_SCB_EZI2C_Enable(SCB2);

/* Read/write EZ_DATA from firmware */
uint8_t buf[4];
Cy_SCB_EZI2C_HwEzReadData(SCB2, 0U, buf, sizeof(buf));
Cy_SCB_EZI2C_HwEzWriteData(SCB2, 4U, buf, sizeof(buf));
```

### Expected Outcome

- **I2C Master**: Write completes with `CY_SCB_I2C_MASTER_WR_CMPLT_EVENT`; no bus error asserted.
- **EZ-I2C Slave**: Master can read/write the shared buffer autonomously; CPU remains in DeepSleep.
- **Hardware EZ Mode**: Transactions complete without clock stretching; `EZ_DATA` accessible via firmware APIs.

## Troubleshooting

| Symptom | Likely Cause | Fix |
|---------|-------------|-----|
| I2C NACK on address | Slave not connected or wrong address | Check slave address, pull-ups, and wiring |
| I2C clock stretching hangs | RX FIFO disabled | Set `useRxFifo = true` in config |
| Bus busy after error | Stuck SDA line | Implement bus-recovery (9 SCL clocks) |
| EZ-I2C not responding | Interrupt not registered | EZ modes require SCB interrupt in NVIC |
| Data rate lower than expected | Incorrect `clk_scb` frequency | Verify `Cy_SCB_I2C_SetDataRate()` output |
| `Cy_SCB_I2C_Init` returns error | SCB not enabled in Device Configurator | Enable the peripheral and re-save `.modus` |

## Configuration Parameters Reference

**I2C (`cy_stc_scb_i2c_config_t`)**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `i2cMode` | `cy_en_scb_i2c_mode_t` | `CY_SCB_I2C_MASTER` | Slave / Master / Master-Slave |
| `useRxFifo` | `bool` | true | Use RX FIFO (reduces clock stretching) |
| `useTxFifo` | `bool` | true | Use TX FIFO (reduces clock stretching) |
| `slaveAddress` | `uint32_t` | 0 | 7-bit slave address (slave mode) |
| `slaveAddressMask` | `uint32_t` | 0xFE | Address mask; 0 bit = don't-care |
| `lowPhaseDutyCycle` | `uint32_t` | auto | SCL low phase clocks (master, set by `Cy_SCB_I2C_SetDataRate`) |
| `highPhaseDutyCycle` | `uint32_t` | auto | SCL high phase clocks (master) |
| `enableDigitalFilter` | `bool` | false | Digital filter for Fast-Plus mode |

## Advanced Usage and Examples

### Wake-from-DeepSleep

SCB I2C slave supports address-match wakeup: the device wakes from DeepSleep when the master addresses it.

Register `Cy_SCB_I2C_DeepSleepCallback` with `Cy_SysPm_RegisterCallback()` before entering DeepSleep.

### DMA Integration

Set `rxFifoTriggerLevel` and `txFifoTriggerLevel` in the I2C config structure to the desired FIFO watermarks. Connect the SCB DMA triggers (`TRIG_IN_MUX_*`) to a DMA channel for zero-copy transfers. Refer to the [DMA driver documentation](dma.md) for DMA channel setup.
